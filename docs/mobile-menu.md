# Menu Mobile Público

## Objetivo

O menu mobile foi adicionado ao layout público do SIS DAVUS para melhorar a navegação em celulares e tablets, especialmente em uso fora do desktop.

## O Que Foi Incluído

- Botão de menu no cabeçalho para telas menores.
- Painel lateral com identidade visual alinhada ao site.
- Atalhos para as principais páginas públicas:
  - Início
  - Módulos
  - Segurança
  - Sobre
  - Contato
  - Entrar
- Fechamento automático do painel ao selecionar uma rota.
- Navegação desktop preservada sem alteração de fluxo.

## Serventia

Antes do menu mobile, a navegação em telas menores ficava menos flexível, principalmente quando o usuário entrava em uma seção e queria retornar ao início ou acessar módulos, contato e login rapidamente.

Com o menu lateral, o usuário consegue circular pelas áreas principais do site com menos esforço, sem depender de voltar pelo navegador ou rolar a página em busca de links.

## Ganhos de Mobilidade

- Melhora a experiência em celulares usados em campo.
- Facilita o acesso em tablets durante operação ou apresentação.
- Reduz atrito para chegar ao login.
- Mantém as seções públicas acessíveis mesmo em telas pequenas.
- Deixa a experiência pública mais consistente com a identidade do SIS DAVUS.

## Validação

- O menu aparece apenas em telas mobile/tablet.
- O painel lista as rotas públicas principais.
- Os links fecham o menu após a seleção.
- O botão de início permite voltar rapidamente para a página inicial.
- A navegação desktop continua usando o menu horizontal.
